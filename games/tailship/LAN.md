# Tailship in Ani's Arcade

Solo as Shade or Deckhand works in this folder — no server.

Couch LAN (same Wi-Fi / people at your desk):
1. Download tailship.zip
2. Unzip and run `python3 server.py` (or `python3 server.py --lan` on a private house IP)
3. Open http://127.0.0.1:8787 — Host local, then Join with the 4-letter code on other machines

No WAN host. GitHub Pages cannot run the WebSocket server.
